◉熄灯盘LIGHTSOUT

这一关的数字从哪来

存档只写在这台设备的 localStorage 里。

玩法：把最后那盏按熄

  1. 按下一格，它和它的上下左右一起翻转——亮的变暗，暗的变亮。边角只有两三个邻居，这不是 bug，是这道题的全部难度来源。
  2. 目标是让所有灯熄灭。
  3. 同一格按两次等于没按，但算两次。按过的格子留四个角标，随时可以再按一次撤掉。
  4. 每一关旁边那个「最少」不是估的：它由 GF(2) 陪集枚举算出，4×4 的全部 65536 个盘面还被按键图广度优先搜索逐个复核过。用那个次数收场，你就是最优解。
  5. 卡住了可以点「答案」把认证解叠在盘面上看；「重开」把这一关恢复到初始盘面，用时与火花一起清零。
键盘
Enter / Space开始、继续；已通关时进下一关
P暂停 / 继续（暂停期间不计时、不接受按键）
R重开这一关
M静音开关（真挂起音频上下文）
F全屏
H 或 ?打开 / 关闭本说明
Esc关闭本说明
点击 / 触摸直接按那一格
